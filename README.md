# Turismo Responsable en Xochimilco

Experiencias de turismo responsable desarrolladas por Santuario Ajolote y cooperativas comunitarias de Xochimilco. Cada visita contribuye a la conservación del ajolote y el humedal.

## Contenido

1. Reserva Natural: Cuemanco, Fernando Celada, Puente de Urrutia
2. Tour: Viaje por el Ecosistema del Ajolote (2h)
3. Tour: Viaje Especial Dedicado al Ajolote (3h)
4. Tour: Amanecer en Xochimilco (4h)
5. Reservas vía WhatsApp
6. Cooperativas comunitarias
